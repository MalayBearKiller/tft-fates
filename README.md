# 🐉 TFT 시즌 4: 운명 (Teamfight Tactics Set 4: Fates) - 웹 시뮬레이터

순수 웹 기술(Vanilla JavaScript + HTML5 Canvas/DOM + Web Audio API)로 구현한 **롤토체스 시즌 4: 운명** 미니 게임입니다.
별도의 복잡한 게임 엔진이나 무거운 라이브러리 없이, 브라우저만 있으면 즉시 실행하여 플레이할 수 있습니다.

## 🌟 핵심 구현 시스템

1. **선택받은 자 (Chosen) 시스템**:
   - 상점에서 확률적으로 타오르는 황금빛 카드로 등장
   - **즉시 2성** 상태로 구매 가능
   - 챔피언의 특성 중 하나가 **x2 (시너지 +1 추가 카운트)**로 판정
   - 추가 체력(+200) 및 능력치 버프
   - 한 번에 1개의 선택받은 자만 소유 가능 (판매 시 상점에 다시 등장)

2. **시즌 4 시그니처 시너지**:
   - 👁️ **광신도 (Cultist)**: 3/6 광신도 달성 시 아군 총 체력 감소 후 하늘에서 **거대 갈리오(폭군/마왕 갈리오)**가 지면을 강타하며 기절과 함께 등장!
   - 🌙 **달빛 (Moonlight)**: 전투 시작 시 최저 성급 유닛 등급 +1. 모두 3성이면 전설의 **4성(★★★★) 황금빛 유닛** 탄생!
   - 🎲 **행운 (Fortune)**: 전투 승리 시 주사위 보너스 골드. 연패 중 승리 시 **대박 잭팟 골드**가 터집니다!
   - ⚔️ **결투가 (Duelist)**: 기본 공격마다 공격 속도 무한 중첩 (최대 8스택)
   - 🚩 **대장군 (Warlord)**: 기본 체력/주문력 증가
   - ✨ **신성 (Divine)**: 체력 50% 이하 또는 6회 공격 시 피해량 감소 및 폭주
   - 💪 **우두머리 (The Boss)**: 세트 고유 특성. 체력 40% 이하 시 맵 구석으로 도망쳐 **윗몸일으키기** 후 체력 100% 회복 & 강화 복귀!

3. **고유 5코스트 챔피언 기믹**:
   - **리 신 (용의 분노)**: 적을 강력한 킥으로 차 날리며, 가장자리에 있는 적은 **장외로 날려보내 즉사(홈런!)**시킵니다.
   - **세트 (대미 장식)**: 적을 들어 올려 밀집 지역에 메가 슬램 폭발 피해를 입힙니다.
   - **칼리스타 (뽑아 찢기)**: 대상의 몸에 창을 박다가 즉사 체력이 되는 순간 즉시 찢어 발깁니다.
   - **카타리나 (죽음의 연꽃)**: 마나가 차면 적진에서 단검 난사 폭풍을 일으킵니다.

4. **100% 자체 합성 신디사이저 사운드 (Web Audio API)**:
   - 외부 mp3 파일 없이 브라우저 자체 오디오 API로 리롤 챠르륵음, 구매 코인음, 레벨업 화음, 타격/스킬음, 갈리오 강림 저음 충격파, 앰비언트 BGM 루프를 합성하여 즉각 재생합니다.

## 🎮 조작법 (Controls)

- **D 키** / **리롤 버튼**: 상점 리롤 (2 골드)
- **F 키** / **경험치 구매 버튼**: 레벨업 경험치 4 구매 (4 골드)
- **E 키** / **판매 구역**: 마우스로 가리킨 기물 판매 (또는 우하단 판매 구역으로 드래그)
- **스페이스바 (Space)** / **전투 시작 버튼**: 준비 단계 종료 및 전투 시작
- **마우스 드래그 앤 드롭**: 벤치 ↔ 전장 기물 배치 이동 및 위치 변경

## 🛠️ 개발 (코드 수정 방법)

`index.html` 은 단일 번들 `app.js` 만 불러옵니다 (`file://` 로 바로 열 수 있도록).
**실제 소스는 `data.js` / `audio.js` / `game.js`** 이고, `app.js` 는 자동 생성 파일입니다.

1. `data.js` (챔피언·시너지·라운드), `audio.js` (사운드), `game.js` (게임 로직) 를 수정
2. 번들 다시 생성:
   ```bash
   python3 build.py
   ```
3. 브라우저 새로고침

디버깅: 브라우저 콘솔에서 `tftGame` (게임 인스턴스), `tftData` (챔피언/라운드 데이터) 로 접근할 수 있습니다.

### 전투 엔진 요약
- 전투는 시뮬레이션 시간(100ms 틱) 기준으로 진행되며, 실제 육각 타일 좌표 위에서 유닛이 이동합니다. 최대 40초, 시간 초과 시 패배.
- 피해 공식: 물리 = 공격력 × 100/(100+방어력), 마법 = 수치 × (1+주문력/100) × 100/(100+마저), 고정 피해는 감소 없음.
- 시너지 효과는 **아군·적군 양쪽에 동일하게** 적용됩니다 (적 광신도도 갈리오를 소환합니다).
- 광신도 갈리오: 팀 전체 체력이 전투 시작 대비 50% 이하가 되면 강림.
